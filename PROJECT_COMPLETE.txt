================================================================================
                          QUICK BUILD GUIDE
================================================================================

Prerequisites:
  1. Windows 10 or 11
  2. Visual Studio 2019/2022 with C++ tools
  3. Qt 6.2+ with MSVC component
  4. CMake 3.16+

Build Steps:
  1. Open "x64 Native Tools Command Prompt for VS 2019"
  2. cd C:\path\to\NEXYTerminal
  3. set Qt6_DIR=C:\Qt\6.5.3\msvc2019_64\lib\cmake\Qt6
  4. mkdir build && cd build
  5. cmake .. -G "Visual Studio 16 2019" -A x64
  6. cmake --build . --config Release
  7. cd bin\Release
  8. C:\Qt\6.5.3\msvc2019_64\bin\windeployqt.exe NEXYTerminal.exe
  9. NEXYTerminal.exe

For detailed instructions, see BUILD.md or QUICKSTART.md

  └── QSettings (Windows Registry)

  └── Forms for customization

Design Pattern: Model-View-Controller
  - MainWindow: Controller
  - TerminalWidget: View
  - TerminalSession: Model
  - Settings: Persistent storage

Communication: Qt Signals & Slots
  - outputReceived signal → appendOutput slot
  - directoryChanged signal → updateStatusBar slot
  - settingsChanged signal → applyTheme slot

================================================================================
                         TROUBLESHOOTING
================================================================================

Common Issues & Solutions:

1. CMake can't find Qt6
   → Set Qt6_DIR environment variable
   → Example: set Qt6_DIR=C:\Qt\6.5.3\msvc2019_64\lib\cmake\Qt6

2. Compiler not found
   → Use Visual Studio Developer Command Prompt
   → Not regular cmd.exe or PowerShell

3. Missing DLL errors
   → Run windeployqt in executable directory
   → Example: windeployqt NEXYTerminal.exe

4. Linker errors
   → Ensure VS and Qt versions match (both 2019 or both 2022)
   → Clean and rebuild

5. Application won't start
   → Check Windows Event Viewer
   → Verify all Qt DLLs present
   → Try running from command prompt to see errors

For detailed troubleshooting, see BUILD.md
